# ASEA Demo Project

First autonomous engineering project demonstration.

## Overview

ASEA (Autonomous Software Engineering Agent) is a lightweight Python starter project demonstrating autonomous task queue management, task execution, and result reporting.

## Setup & Installation

1. Ensure you have Python 3.8+ installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Application

Run the primary entry point:
```bash
python main.py
```

## Running Tests

Execute the test suite with pytest:
```bash
pytest
```
